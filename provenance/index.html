02 / Verify

Check the PDF offline

Extract the verification bundle and save the fixed-version PDF beside it. With Python 3 and OpenSSL 3 installed, run:

python3 verify.py v3.1.0.pdf

The program checks the PDF, its original manifest entry, the timestamp signature, the pinned signer and archived certificate evidence. It makes no network requests.

Verification relies on FreeTSA. Confirm the root certificate fingerprint through an independent trusted source. The archived revocation list supports checks at the signed time; it is not a current revocation-status check. TSA accuracy was unspecified.
